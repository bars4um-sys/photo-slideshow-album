# Как добавить фотографии

## Теперь работает автоматически!

Просто положите фотографии в папку `public/photos/` — они автоматически появятся в слайд-шоу.

### Поддерживаемые форматы
- `.webp` (рекомендуется)
- `.jpg` / `.jpeg`
- `.png`
- `.gif`
- `.avif`

### Порядок слайдов
Фотографии сортируются по имени файла. Используйте осмысленные имена:
- `p01.webp`, `p02.webp`, `p03.webp` — будут показаны в этом порядке
- `01-лето.jpg`, `02-осень.jpg` — тоже работает

### Как добавить фото
1. Положите файл в `public/photos/`
2. Обновите страницу — фото автоматически появится в слайд-шоу

### Как удалить фото
1. Удалите файл из `public/photos/`
2. Обновите страницу — фото исчезнет из слайд-шоу

### Как изменить порядок
Переименуйте файлы так, чтобы сортировка давала нужный порядок:
- `p01.webp` → первый
- `p02.webp` → второй
- и т.д.

### Оптимизация
Для лучшей производительности:
- Используйте формат `.webp` — меньше размер, лучше качество
- Рекомендуемый размер: 1200×800px или меньше
- Не используйте файлы больше 2 МБ
