# Как добавить свои фотографии в слайд-шоу

## 3 способа добавления фотографий

### Способ 1: Использовать ссылки из интернета (САМЫЙ ПРОСТОЙ!)

1. Найдите фотографию в интернете
2. Щёлкните правой кнопкой → "Копировать адрес изображения"
3. Откройте файл `app/page.tsx`
4. Найдите нужную строку с `image:` и вставьте URL

**Пример:**
```typescript
{
  type: 'photo' as const,
  image: 'https://example.com/my-photo.jpg',  // ← Замените эту ссылку
},
```

**Источники фотографий:**
- [Unsplash](https://unsplash.com) - бесплатные красивые фото
- [Pexels](https://pexels.com) - ещё больше бесплатных фото
- [Pixabay](https://pixabay.com) - качественные фотографии
- Ваш облачный диск (Google Drive, Яндекс.Диск и т.д.) - просто получите публичную ссылку

---

### Способ 2: Загрузить фотографии локально (в проект)

Подходит если вы хотите хранить фото вместе с проектом.

**Шаг 1:** Создайте папку для фото
```
v0-project/
  ├── public/
  │   └── photos/        ← Создайте эту папку
  │       ├── photo1.jpg
  │       ├── photo2.jpg
  │       └── photo3.jpg
```

**Шаг 2:** Положите фотографии в папку `public/photos/`

**Шаг 3:** Откройте `app/page.tsx` и используйте пути:
```typescript
{
  type: 'photo' as const,
  image: '/photos/photo1.jpg',  // ← Путь к вашей фото
},
```

**Преимущества:**
- Фото загружаются быстрее (одновременно с сайтом)
- Не зависят от внешних сервисов
- Можно развернуть везде

---

### Способ 3: Облачное хранилище Vercel Blob

Если вы хотите обновлять фото без редактирования кода.

**Шаг 1:** Откройте Settings в v0 (правый верхний угол)

**Шаг 2:** Перейдите в **Integrations** и подключите **Vercel Blob**

**Шаг 3:** Загрузьте фотографии и получите URL

**Шаг 4:** Используйте URL в `app/page.tsx`:
```typescript
{
  type: 'photo' as const,
  image: 'https://blob-url-from-vercel.jpg',
},
```

**Преимущества:**
- Можно обновлять фото без переразвёртывания сайта
- Неограниченное хранилище
- Высокая скорость доставки

## Как добавить или удалить фотографию

### Добавить новую фотографию

Скопируйте этот блок и вставьте его между другими фото:
```typescript
{
  type: 'photo' as const,
  image: 'https://ваша-фотография-url.jpg',
},
```

### Удалить фотографию

Просто удалите весь блок:
```typescript
// Удаляем это:
// {
//   type: 'photo' as const,
//   image: 'https://...',
// },
```

## Советы

1. **Размер фотографий:** Лучше всего использовать фото с соотношением 4:3 или 16:9 (ширина больше чем высота)

2. **Рекомендуемое разрешение:** 1200x800 пикселей или больше

3. **Формат:** JPG, PNG, WebP - все работают

4. **Быстрый тест:** Откройте v0 Preview (кнопка слева) и сразу увидите результат!

5. **Автосохранение:** После изменения `app/page.tsx` сайт обновится автоматически

## Часто задаваемые вопросы

**Q: Почему фотография не загружается?**  
A: Проверьте URL - скопируйте его в браузер и убедитесь, что фото открывается

**Q: Как получить ссылку на фото с компьютера?**  
A: Используйте Способ 2 (загрузите в `public/photos/`) или загрузите на облако и получите публичную ссылку

**Q: Фотография загружается медленно**  
A: Используйте меньший размер файла (оптимизируйте через [TinyPNG](https://tinypng.com) или [Squoosh](https://squoosh.app))

**Q: Как изменить текст в начале и конце?**  
A: Отредактируйте `intro` и `outro` блоки в `app/page.tsx`
