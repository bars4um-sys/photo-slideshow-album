# Элегантное слайд-шоу 📸

Красивое интерактивное слайд-шоу с эффектом 3D перелистывания страниц, динамическим фоном и плавными переходами.

## 🎨 Особенности

- ✨ **3D эффекты перелистывания** - имитация перелистывания страниц альбома
- 🎬 **Плавные переходы** - красивая анимация при смене слайдов
- 🌌 **Динамический фон** - анимированные градиенты и размытые элементы
- ⌨️ **Клавиатурная навигация** - используйте стрелки ← и → для управления
- 📱 **Адаптивный дизайн** - отлично выглядит на всех устройствах
- 🎯 **Интерактивная индикация** - показатель текущего слайда и кликабельные точки
- ⏱️ **Автоматическое воспроизведение** - слайды переключаются каждые 5 секунд

## 🚀 Использование

### Базовый пример

```typescript
import Slideshow from '@/components/slideshow'

const slides = [
  {
    type: 'intro',
    title: 'Заголовок',
    description: 'Описание вводного экрана',
  },
  {
    type: 'photo',
    image: 'https://example.com/photo1.jpg',
  },
  {
    type: 'photo',
    image: 'https://example.com/photo2.jpg',
  },
  {
    type: 'outro',
    title: 'Спасибо',
    description: 'Заключительный экран',
  },
]

export default function Page() {
  return <Slideshow slides={slides} />
}
```

## 📝 Типы слайдов

### 1. **Intro слайд** (Вводный экран)
```typescript
{
  type: 'intro',
  title: 'Ваш заголовок',
  description: 'Ваше описание',
}
```

### 2. **Photo слайд** (Фотография)
```typescript
{
  type: 'photo',
  image: 'URL к вашей фотографии',
}
```

### 3. **Outro слайд** (Заключительный экран)
```typescript
{
  type: 'outro',
  title: 'Спасибо за внимание',
  description: 'Заключительное сообщение',
}
```

## ⌨️ Навигация

- **Кнопка "Следующая →"** - переход на следующий слайд
- **Кнопка "← Предыдущая"** - переход на предыдущий слайд
- **Точки-индикаторы** - кликните для прямого перехода к слайду
- **Стрелка → на клавиатуре** - следующий слайд
- **Стрелка ← на клавиатуре** - предыдущий слайд
- **Автоматическое воспроизведение** - каждые 5 секунд

## 🎨 Кастомизация

### Изменение цветов фона

Отредактируйте градиент в `components/slideshow.tsx`:

```typescript
<div className="bg-gradient-to-br from-slate-900 via-purple-900 to-slate-900">
  {/* Измените цвета здесь */}
</div>
```

### Изменение времени воспроизведения

В файле `components/slideshow.tsx` найдите:

```typescript
const interval = setInterval(() => {
  paginate(1)
}, 5000) // Измените 5000 на желаемое количество миллисекунд
```

### Изменение анимационных эффектов

Отредактируйте `variants` и `transition` в компоненте для создания собственных эффектов перелистывания.

## 🌐 Поддерживаемые форматы

- ✅ JPEG, PNG, WebP
- ✅ URL из интернета (Unsplash, Pexels и т.д.)
- ✅ Локальные изображения из папки `public/`

## 💡 Советы

1. Используйте высокое качество изображений (минимум 1200x800px)
2. Оптимизируйте изображения перед загрузкой для быстрой загрузки
3. Добавьте от 5 до 10 слайдов для лучшего впечатления
4. Используйте контрастные цвета для заголовков и описаний
5. Протестируйте навигацию со стрелками на клавиатуре
