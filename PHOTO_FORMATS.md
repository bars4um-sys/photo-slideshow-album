# Форматы и соотношения сторон фотографий

Слайд-шоу автоматически адаптируется к любым соотношениям сторон фотографий!

## Как это работает

Система определяет соотношение сторон каждой фотографии при загрузке и применяет правильный режим отображения:

- **Альбомные фотографии** (широкие, ratio > 1.3)
  - Используется режим: `object-fit: cover`
  - Фотография заполняет весь экран
  - Может быть небольшая обрезка по краям
  - Пример: 1920×1080, 1600×900, 16:9

- **Портретные фотографии** (узкие, ratio ≤ 1.3)
  - Используется режим: `object-fit: contain`
  - Фотография вмещается целиком на экран
  - Могут быть пустые полосы сверху/снизу
  - Пример: 1080×1920, 800×1200, 9:16

- **Квадратные фотографии** (ratio ~1.0)
  - Используется режим: `object-fit: contain`
  - Фотография вмещается целиком с пустыми полосами

## Рекомендации

### Идеальные размеры

**Для лучшего качества используйте фотографии с этими разрешениями:**

- **Альбомные (16:9)**
  - 1920 × 1080 (Full HD)
  - 1600 × 900
  - 2560 × 1440 (2K)

- **Портретные (9:16)**
  - 1080 × 1920
  - 900 × 1600
  - 1440 × 2560 (2K)

- **Квадратные (1:1)**
  - 1080 × 1080
  - 1200 × 1200

### Минимальные размеры

Фотографии могут быть меньше, но рекомендуется:
- Минимум **800px** по длинной стороне
- Минимум **600px** по короткой стороне

### Оптимизация

- **Формат**: JPG или WebP для лучшей сжатия
- **Качество**: 75-85% JPG качества обычно достаточно
- **Размер файла**: 200-500 KB на фотографию

## Примеры использования

### Альбомная фотография (будет заполнять весь экран)
```typescript
{
  type: 'photo' as const,
  image: 'https://example.com/sunset-1920x1080.jpg', // 16:9
}
```

### Портретная фотография (вмещается целиком)
```typescript
{
  type: 'photo' as const,
  image: '/photos/portrait-1080x1920.jpg', // 9:16
}
```

### Квадратная фотография (центрирована)
```typescript
{
  type: 'photo' as const,
  image: '/photos/square-1200x1200.jpg', // 1:1
}
```

## Правила обрезки

Система автоматически центрирует фотографии - обрезка происходит равномерно со всех сторон.

**Избегайте размещения важных деталей по краям портретных или квадратных фотографий**, так как они могут быть обрезаны при отображении в альбомном режиме на мобильных устройствах.

## Часто задаваемые вопросы

**Вопрос:** Фотография обрезается сверху/снизу, как это исправить?
**Ответ:** Это портретная фотография и она отображается в режиме `object-fit: contain`. Это нормально. Если хотите, чтобы она заполнила весь экран, обрежьте её до альбомного формата.

**Вопрос:** Между фотографией и краями экрана видны полосы, это ошибка?
**Ответ:** Нет, это нормально для портретных или квадратных фотографий. Это предотвращает искажение фотографии.

**Вопрос:** Какое соотношение сторон использовать?
**Ответ:** Рекомендуется 16:9 (альбомное). Но система работает с любыми соотношениями!
